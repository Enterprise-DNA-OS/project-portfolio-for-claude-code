# weekly-review

Draft a review from current delivery, attention and capacity. Read CLAUDE.md first.

Run `npm run portfolio -- weekly-review --json`. Replace example values with the operator's records; never run example writes against their database.

Read the relevant records first. Names match without case; partial IDs work. If ambiguous, show the candidates and wait for a choice. Present dates, currency and missing evidence plainly. Never invent facts or send a message.

The CLI writes a draft under drafts/. Read it, name the decisions required and the owners, and leave it for review. For printable paperwork run `npm run docs`. Nothing sends.
